## 结构诊断与选择

| 问题与证据 | 根因 | 当前归属 |
| --- | --- | --- |
| 顶部 `navigation`、检测 `ModeTabs`、移动页内切换各自定义选中样式 | 同一展示契约被页面分别实现（A1） | `components/SegmentedControl` 统一 DOM 展示与状态样式，链接保持链接、局部选择保持按钮 |
| 检测独用 `detect-heading`，其余工作页用 `WorkHeader` | 页面骨架重复（A1） | 所有工作页共享 `work-page`、`GlassPanel`；页面名由导航胶囊与 `document.title` 承担，页内 `WorkHeader` 标题已随后清理移除 |
| 页面分别判断 `authenticated`，各自放登录按钮 | 账号准入由业务页重复管理（A2） | `App` 在装配受保护页面前统一门禁；首页保留右上角唯一账号入口 |
| 检测只保存 `reportId`，不把报告交给视图 | 本轮事实被丢弃，UI 无法投影专项测量（A2） | 检测会话持有唯一的本轮 result，先发布测量再补全文本；纯投影与保存都使用该结果 |
| 检测没有总采集时钟，问答需手动启闭 | UI 操作取代了检测用例，三模式流程脱节（A2） | 会话统一 60 秒时钟、准备、自动问答、分析和保存；UI 只传单调时间及题目已显示事件 |
| `capture/status` 将硬件心率/温度序列化至 HTTP，UI 读取该块 | 冻结的设备实现外溢（A4） | 保留 capture 内原实现，删除网关 serializer/schema/HTTP 投影；FacePhys 同轮测量是唯一生理展示输入 |
| 删除/新增报告后需要手动刷新 | 读取生命周期和变更未形成明确依赖 | 报告服务统一发布保存、分析归档与删除成功的变更，列表订阅后重读；参数/可见性变化沿现有读取生命周期处理 |

仅改 CSS 不能消除重复的行为与事实来源；复制三套检测或引入通用状态机/查询框架都会增加本轮维护成本。按本轮明确选择，玻璃通路交给 `simple-liquid-glass`（组件级实时渲染 + scene provider 背景），删除固定视口 PNG 管线与自建的文档级渲染器。

未发现需要引入新框架的 A3 依赖倒挂；继续保留领域/用例、I/O、React 视图之间的现有边界。没有添加通用状态机、查询库或第二套玻璃渲染器。

## 能力所有权

- `App.tsx`：唯一 History 写入者、路径与查询参数、账号门禁、返回登录前地址与导航。登录令牌作为应用工作区的 key，统一建立和销毁检测与综合分析状态；同一登录中的切页继续使用该工作区。未登录不得挂载检测/报告/分析/数字人页面。首页和认证表单公开。
- `AppShell`：品牌、导航与右上角账号入口、主内容焦点。Shell 不引用具体业务页，背景归文档级渲染器所有。
- `application/detection.ts`：唯一检测令牌、准备事实、时钟、当前题、临时转写、本轮 result、封存与保存重试。测量与完整报告按阶段更新同一 result，视图和保存共用这一份结果。核心不使用浏览器计时器。
- `application/reports.ts`：报告查询和变更入口。成功保存、综合分析归档和删除后统一通知列表刷新；路由和检测模式不再拼接保存编号触发刷新。
- `useDetectionSession`：为三种模式各持有一轮会话，共用一个时钟；页面卸载不销毁会话，退出该登录工作区时统一释放。
- `DetectionScreen`：将当前会话快照及题目展示确认连接到页面；预览拥有独立资源，不随检测模式或移动子视图切换重连。
- `domain/detectionResults.ts`：只作标签、单位、精度与字段投影，不请求、不计时、不推导新的医学判断。
- `application/preview` 与 `api/preview`：自动订阅后端设备视频、重连、离开释放；不使用浏览器摄像头。
- `useLatestQuery`：请求来源与 React 生命周期。参数/来源变更时旧值立即失效；过期请求不得提交。窗口恢复可见/焦点时重新读取。
- `src/components/GlassPanel.tsx`：唯一玻璃库所有者，导出 Scene 和共享表面；布局档位独立归 `components/layout.ts`。库拥有捕获与渲染生命周期，页面只提供内容。详见 [玻璃边界](../glass/README.md)。

## 与 main 核对的检测契约

| 模式 | 准备 | 采集/问答 | 专项显示 |
| --- | --- | --- | --- |
| 健康 | 截图并分析舌象，展示观察事实，然后开始一分钟问诊；可重拍 | 60 秒；首题来自 begin；显示题目后 start；临时转写确认与最长 15 秒自动闭题；下一题来自后端 | 舌色、苔色、裂纹、齿痕、体质判定 |
| 疲劳 | 设备预检 | 60 秒自然状态采集，无问答 | 眨眼次数/频率、哈欠次数、点头次数、闭眼占比、说话占比、疲劳指数 |
| 情绪 | 取本轮问题，然后 begin | 与健康共用 60 秒采集与自动问答 | 生气、厌恶、恐惧、开心、平静、难过、惊讶；喜怒哀虑词频 |

三者结束采集后都自动封存并请求测量。测量完成即展示同轮指标，健康与情绪报告随后复用该结果生成正文，疲劳使用测量阶段生成的规则建议。报告完成后自动保存。健康报告完成后，重新问诊先回到舌象拍摄，不能沿用上轮望诊事实。问完最后一题仍持续采集至时间边界。允许确认后提前结束。FacePhys 默认收起；展开生理窗口才显示心率、呼吸率、SDNN、RMSSD、pNN50、NN50。全部取本轮 `physiology`；缺测显示破折号和当前信号判定，实际计数为零时显示 0。

与 main 的显示规则一致：pNN50 已为百分数，不再次乘 100；疲劳 `score_fraction` 转换为百分制；表情计数无样本时缺测，有样本时稀疏类别按零计。

## 生命周期不变量

1. 同时只有一个开始/准备/分析操作；同题转写与闭题串行。采集截止时等待正在进行的反馈，再由后端封存并结清活动题。
2. 分析失败保留同一轮令牌；重试复用已成功的封存，不重采集。取消、退出与卸载释放令牌；迟到 begin 返回的令牌也必须释放。
3. 报告生成后释放设备；保存失败保留报告，只重试保存，不重分析。未保存的结果不能被开始按钮或模式切换悄然覆盖。
4. 登录期间每种模式的会话由应用持有，导航只选择当前视图。跨页和切换模式保留采集、问答进度、测量与报告。设备每次只录制一轮，报告生成期间可启动下一模式。关闭/刷新浏览器用 `beforeunload` 提醒未保存检测。
5. 报告选中态以 `/reports?id=N` 为唯一来源。Back/Forward 与深链共用读取，不允许迟到详情覆盖新地址。
6. 检测离线只写“设备未连接”；数字人舞台只写“未接入”。没有额外人体图、模拟设备数据、连接按钮或手动刷新按钮。
7. 单片机心率/温度只留在 capture 的冻结代码中。网关、analysis、compute 与 React 不引入其读数或类型；静态边界与 HTTP 实测同时保护此规则。
